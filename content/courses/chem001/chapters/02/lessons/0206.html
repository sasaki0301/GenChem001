Orbital Diagrams: Pauli Exclusion Principle and Hund’s Rule

Electron configurations tell us how many electrons occupy a subshell. Orbital diagrams show how those electrons are represented in its individual orbitals.

Learning objectives

By the end of this lesson, you should be able to:

  • Interpret boxes and arrows in an orbital diagram.
  • Apply the Aufbau principle, Pauli exclusion principle, and Hund’s rule to ground-state arrangements.
  • Draw and validate orbital diagrams for common neutral atoms.
  • Connect an orbital diagram with electron configuration and identify unpaired electrons.
Scope: Worked ground-state examples focus on common neutral atoms among the first 20 elements, building on the sequence from Lesson 5.

1. Read the symbols

Each box represents one orbital. An arrow represents one electron; its direction represents one of two spin projections in this model. A single box can contain at most two electrons, shown with opposite arrows when paired.

How many boxes?

An s subshell contains one orbital, so draw one box. A p subshell contains three orbitals, so draw three boxes. A d subshell has five orbitals and an f subshell has seven.

For example, 2p⁴ means four electrons distributed across the three 2p orbitals. It does not mean four electrons in each box.

The direction chosen for a single unpaired arrow is conventional: a whole set of equivalent ground-state diagrams can use the opposite overall spin direction. What matters is the relationship between spins and the number of electrons.

2. Apply the three principles

Principle What it tells us
Aufbau principle Use lower-energy available orbitals before higher ones in the introductory ground-state filling approach.
Pauli exclusion principle An orbital can hold at most two electrons; if paired, they have opposite spins.
Hund’s rule For the ground state, electrons occupy equal-energy orbitals singly with parallel spins before additional electrons pair.

For the first 20 neutral atoms, use the introductory order 1s → 2s → 2p → 3s → 3p → 4s. Later elements and ions require care because subshell energies can be close and some ground states differ from a simple filling prediction.

Hund’s rule describes the lowest-energy arrangement within equal-energy orbitals. An arrangement that does not follow it is not necessarily forbidden in every excited state; in this lesson we are checking ground-state diagrams.

3. Draw ground-state orbital diagrams

  1. Find the neutral atom’s electron count from its atomic number.
  2. Write the subshell configuration using the introductory filling sequence.
  3. Draw one box for each s orbital and three boxes for each p subshell used.
  4. Place arrows according to Pauli’s principle and Hund’s rule, then count the arrows.

4. Validate and correct a diagram

  1. Count: Does the number of arrows match the neutral atom’s electron count?
  2. Check Aufbau: For the stated scope, are lower-energy subshells filled in the introductory ground-state sequence?
  3. Check Pauli: Does each box contain no more than two electrons, with opposite arrows if paired?
  4. Check Hund: Are equal-energy orbitals singly occupied with parallel spins before electrons pair in the ground-state diagram?

Error A · Two identical spins in one orbital

↑↑
One orbital

Two same-direction arrows in one box violate the Pauli exclusion principle. For two electrons in that orbital, use opposite arrows.

Error B · Pairing too early

↑↓↑↓ 
2p

This p⁴ example has opposite spins in each pair, so those pairs do not themselves violate Pauli. But pairing twice while an equal-energy p orbital is empty is not the Hund’s-rule ground state. The ground-state pattern has one pair and two parallel singles.

7. Key terms and takeaways

  • Box: one orbital; arrow: one electron and its spin projection.
  • Aufbau: use the introductory lower-energy filling sequence for the ground-state examples in this lesson.
  • Pauli: at most two electrons per orbital, with opposite spins when paired.
  • Hund: for the ground state, occupy equal-energy orbitals singly with parallel spins before pairing.
  • Validation: check electron count, order, capacity, spin, and the required state.
