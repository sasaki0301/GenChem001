Historical Classification of Elements and Mendeleev’s Periodic Table

As scientists discovered more elements, remembering their properties individually became difficult. Could a pattern organize what was already known—and suggest what had not yet been found?

Learning objectives

By the end of this lesson, you should be able to:

  • Compare the approaches of Döbereiner, Newlands, Mendeleev, and Moseley.
  • Explain how Mendeleev used atomic masses and recurring properties to organize elements.
  • Explain why he left gaps and how later discoveries provided evidence for his predictions.

Key idea: Scientific models can organize existing evidence and also make predictions that later observations can test.

1. Searching for patterns

An element is a type of matter made of atoms with the same number of protons. Long before the modern table existed, scientists compared observable properties and the atomic masses available to them. Their systems each explained some patterns, but no early system accounted perfectly for all the known elements.

Döbereiner’s triads

Johann Wolfgang Döbereiner noticed that some groups of three elements had similar properties. In certain triads, the atomic mass of the middle element was approximately the average of the other two.

Worked example · Lithium, sodium, and potassium

Using modern approximate atomic-mass values for illustration: lithium ≈ 6.94; sodium ≈ 22.99; potassium ≈ 39.10.

(6.94 + 39.10) ÷ 2 = 23.02

The average, 23.02, is close to sodium’s approximate value, 22.99. The pattern was useful, but only some elements could be grouped convincingly this way.

These rounded modern values illustrate the pattern; they are not presented as Döbereiner’s original measurements.

Newlands’ Law of Octaves

John Newlands arranged elements mainly by increasing atomic mass and noted that similar properties seemed to recur at intervals. His Law of Octaves compared this recurrence with musical octaves. It helped draw attention to repeating properties, though the pattern worked better for some lighter elements than for all known elements.

Compare: Triads focused on selected groups of three similar elements; Newlands looked for recurring properties across a sequence arranged by mass.

2. Mendeleev’s approach

Dmitri Mendeleev arranged the known elements mainly by increasing atomic mass while comparing their chemical and physical properties. He looked for periodicity: patterns in properties that recur as elements are arranged in an ordered sequence.

  1. He compared available atomic masses and observed properties of elements and their compounds.
  2. He organized elements so that those with similar properties appeared in related positions.
  3. Where the pattern suggested that no known element fit, he left a gap and proposed that an element remained undiscovered.

When mass and properties seemed to conflict

Mendeleev did not follow mass order blindly. For example, he placed tellurium before iodine to keep them with elements of similar chemical properties, even though tellurium’s commonly listed atomic mass is slightly greater than iodine’s. In the modern table, their atomic numbers—52 and 53—give that same order.

This example shows how he used more than one kind of evidence to judge placement.

Predicting an undiscovered element

Mendeleev left a gap near silicon and used the properties of neighboring elements to predict an element he called eka-silicon. Later, germanium was discovered. Several of its observed properties were close to his predictions, providing evidence that the pattern had predictive value.

Prediction

A gap and its neighboring elements suggested a missing element and properties it might have.

Test

Scientists later discovered germanium and compared measured properties with the earlier prediction.

A successful prediction supports a model; it does not mean every prediction is exact or that a model can never be revised.

3. Moseley and the modern periodic table

Henry Moseley’s work using characteristic X-ray spectra provided evidence for organizing elements by atomic number. Today, atomic number is defined as the number of protons in an atom’s nucleus. The modern periodic table is arranged by increasing atomic number, and properties recur periodically with this order.

Do not confuse atomic mass with atomic number. Atomic number identifies the element. We will study the particles within atoms and isotopes in Chapter 3.

5. Key terms and takeaways

  • Triad: a selected set of three similar elements with an approximate mass relationship.
  • Law of Octaves: Newlands’ proposed recurrence of properties in a mass-ordered sequence.
  • Periodicity: the recurring pattern of element properties in an ordered arrangement.
  • Mendeleev’s contribution: arranged elements mainly by mass and properties, left gaps, and predicted properties of missing elements.
  • Modern organizing principle: increasing atomic number, the number of protons.
  • Scientific evidence: comparing predictions with later observations helps evaluate a model.
